# RJ番号リンカー (for DLsite)

SNS などに書かれた DLsite の作品番号（`RJ01038533` など）を自動でリンクに変換し、クリックするだけで作品ページを開けるようにする Chrome / Edge 拡張機能です。

> [!NOTE]
> 本拡張機能は非公式のツールであり、DLsite および運営会社とは一切関係ありません。

## 機能

- 作品番号の自動リンク化（`RJ` / `RE` / `VJ` / `BJ` + 6桁または8桁）
- スクロールで読み込まれる投稿にも自動で対応
- ポップアップから番号を入力して直接開く
- 対応サイト以外でも、番号を選択して右クリック →「DLsiteで開く」で利用可能
- 自動リンク化のオン/オフ切り替え

## 対応サイト（自動リンク化）

- X (Twitter)
- Bluesky
- pixiv
- 5ちゃんねる
- Misskey.io
- YouTube
- DLsite ぽみゅ

## インストール方法

1. [Releases](../../releases/latest) から `rj-linker-x.x.x.zip` をダウンロードし、任意のフォルダに展開します。
   - 展開したフォルダは削除・移動しないでください（削除すると拡張機能が動かなくなります）。
2. ブラウザで拡張機能の管理画面を開きます。
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 「**デベロッパーモード**」をオンにします。
4. 「**パッケージ化されていない拡張機能を読み込む**」をクリックし、展開したフォルダ（`manifest.json` が入っているフォルダ）を選択します。

### 更新方法

1. 新しいバージョンの zip をダウンロードし、前回と同じフォルダに上書きで展開します。
2. 拡張機能の管理画面で、本拡張機能の再読み込みボタン（↻）を押します。

## 使い方

- 対応サイトを開くと、作品番号が青い点線下線のリンクに変わります。クリックすると作品ページが新しいタブで開きます。
- ツールバーのアイコンをクリックすると、オン/オフの切り替えと番号入力ができます。
- ツールバーにアイコンが表示されない場合は、パズルピースのアイコンからピン留めしてください。

## プライバシー

閲覧履歴や個人情報などのデータは一切収集・送信しません。ページ内のテキストの書き換えは、お使いのブラウザ内でのみ行われます。
